# frontend — простой SPA рабочего репозитория

React + TypeScript + Vite. Нужен, чтобы проверять функционал backend через интерфейс, визуально совпадающий с прототипом Евгения (`index.html` в общем репозитории): стили прототипа перенесены без изменений в `src/styles/prototype.css`.

В общий репозиторий `kayeros/IT-career-navigator` не выгружается: там `frontend/` ведёт Евгений.

## Запуск

Всё вместе (база, api, frontend) — из корня репозитория:

```bash
docker compose up --build -d
docker compose exec api /app/api seed
```

Сайт — http://localhost:3000.

Разработка с горячей перезагрузкой (нужен Node.js 22): `npm ci`, затем `npm run dev` → http://localhost:5173, `/api` проксируется на `http://localhost:8080`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run lint` | ESLint |
| `npm run gen:api` | типы API из `../api/openapi.yaml` в `src/api/schema.d.ts` (руками не править) |

## Что работает на реальном API

Регистрация и вход, каталог, карта профессии (блоки → темы → материалы), отметки «Изучено», процент соответствия вакансиям и недостающие навыки, личный кабинет с прогрессом по профессиям.

Профориентация, оценка навыков, план, подписка, восстановление пароля и форма обратной связи — заглушки «в разработке»: в API их ещё нет.
